# AI Perks

A responsive, buildless business dashboard inspired by the publicly described features of AiPraktor. The authenticated reference dashboard was not accessible, so this is an original interpretation rather than an exact visual clone.

## Run locally

From this directory, run `python3 -m http.server 8080 --directory dist` and open http://localhost:8080.

## Features

Overview with sample revenue charts, unified demo inbox, order creation and status management, filtered CSV exports, lead pipeline, automation preferences, product catalog, bookings, knowledge documents, global search and workspace settings. Local records persist through localStorage. Reset is available in Settings.

## Scope

This is a frontend prototype. Overview and analytics are illustrative sample reports. Social messaging, AI inference, payment processing, couriers, login, shared team storage and server-side automation are not connected. Messages are stored only in the browser. Multi-user production operation requires authenticated backend services, a database and platform integrations. Google Fonts is optional; system sans-serif fonts are used if unavailable.
